# Comercio de Elia

Habla con Elia y usa **Siguiente** para consultar cada oferta. La ventana muestra precio y existencias de tu bolsa. El botón de compra o venta confirma una operación por unidad o lote.

| Operación | Coste o ingreso | Requisito |
|---|---|---|
| Comprar 2 de madera | 5 oro | Capacidad de recursos |
| Comprar una ración | 3 oro | Espacio en la bolsa |
| Vender una ración | Recibes 1 oro | Tener una ración y capacidad de oro |
| Comprar un chaleco reforzado | 8 oro y 4 madera | Taller construido, progresión y espacio |

El juego comprueba fondos, existencias y capacidad antes de aplicar la operación. Las transacciones exitosas guardan el saldo y la bolsa. Desde Inventario puedes usar una ración para recuperar hasta 4 PV o equipar el chaleco. Durante la decisión del cruce, Elia presenta primero las opciones de campaña.
